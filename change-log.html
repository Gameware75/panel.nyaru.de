Changelog

Version 0.0.2

Initial release of NyaruVTPanel

Version 1.0.0

✨ Added

  • Purchase confirmation and error screens added
  • Price now visible when hovering over a product
  • For certain categories, instead of 4 images, only 2 narrower images are displayed

🔄 Changed

  • Category switch improved:
    • Instead of showing all category icons at once, only 3 are now displayed: one large icon in the center, with smaller icons to the left and right, and arrows to navigate between categories.
    • The frame around the categories has also been enhanced for a more refined look.
  • The ranking list is now viewable even when NyaruVT is offline.
  • Your username is now highlighted in the ranking list.
  • Increased the size of the preview image in the product purchase confirmation prompt.
  • Images in the panel now retain their size without distortion (object-fit: contain).
  • A subtle white background has been added behind product images in the product overview to support transparent images.
  • Replaced the user icon with the user's profile picture.

🐞 Fixed

  • Improved page load times between transitions through cache optimization.

🗑️ Removed

  • Removed the "Created by gameware75" footer from the main screen.

Version 1.0.2

✨ Added

  • Custom Lock Feature: Added a lock functionality to restrict access to the panel.
  • Added an icon to indicate when a product is in cooldown, displaying a custom message explaining the reason for the restriction.

🔄 Changed

  • Offline Screen Removed: The dedicated offline screen has been completely removed. Users can now browse all products, view the ranking list, and access other features even when NyaruVT is offline. However, purchasing remains unavailable in offline mode.

🐞 Fixed

  • Resolved an issue where pages with large images displayed incorrect page counts.
